# The Exigo Question

**Wayroo integrates with Exigo and any other back office.** That is confirmed, and it changes the shape of the market: the addressable set stops being *"DSOs willing to replace a back office"* and becomes *"any DSO."*

**Both live prospect records are Wayroo-first.** Color Street was a Wayroo-only pitch with no Freedom upsell; Jordan Essentials was a Wayroo attach. **Neither was won by selling a back-office replacement.**

## Why it is not the move today

| Blocker | |
|---|---|
| 🔴 **No in-product access** | The entire advantage of Land-and-Expand is advertising inside software we own. **At an Exigo client we own nothing** — it reverts to a cold new-logo motion. |
| **No relationship** | Land-and-Expand works because 55 clients already signed |
| **Capacity** | One closer, already deprioritised for Track 1 |
| **The core is unproven** | Selling a motion we have not measured |

> ### The strategic tension worth naming
>
> **The thing that makes Land-and-Expand work — owning the distribution surface — is exactly what an Exigo client does not give us.** Wayroo-led entry is a genuinely different motion wearing the same product.
>
> **It should be evaluated as new-logo sales with a better product**, not as an extension of this one.

# The Lightweight Test — when the core is proven

**Do not run this yet. Preserved so it is ready.**

| | |
|---|---|
| **Question** | Will a DSO on Exigo adopt Wayroo without changing back office? |
| **Test** | **One** Exigo-based DSO. **Do not build a programme.** |
| **Route in** | Color Street is the closest analogue — no ByDesign relationship, custom stack, and **its CTO endorsed the integration architecture (Path B).** |
| **Duration** | 60 days to a yes/no on technical feasibility and appetite |
| **Success** | A signed pilot with ProPay approval |
| **Kill** | Integration proves materially harder than Path B suggests, **or the cycle exceeds 90 days** |

**Cheapest first step, and it costs one conversation:** **re-open Color Street.** The deal stalled in May with a CTO-endorsed architecture and an unresolved commercial. **Its August reunion — the named deal-closing forcing function — passed with nothing recorded.** Ask what happened.

# Conditional Playbook

**If the test succeeds:**

| Change | |
|---|---|
| **Positioning** | *"The selling app that comes with your back office"* **breaks** — Wayroo would not come with theirs. Needs a new category frame. |
| **Channel** | 🔴 **The Revolution placement does not exist here.** Back to conventions, field leaders, and direct sales. |
| **Commercial** | *"Included with a subscription you already hold"* has no referent. **A price would have to exist** — likely the per-rep model we deliberately did not charge. |
| **Product** | Path B formalised as a supported integration pattern |
| **Sales** | Requires a closer. **The motion's defining advantage — no sales cycle — is gone.** |

> **Three of the four load-bearing elements of the current positioning stop being true.** That is not a reason against it — it is the work it would require, and it should be understood before anyone calls it adjacent.
