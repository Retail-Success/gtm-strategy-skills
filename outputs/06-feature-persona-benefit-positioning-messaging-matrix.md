## How to Use This Matrix

**For sales reps preparing a call:**
1. Identify the persona(s) you'll be talking to (Brian B-style CEO? Edmond-style CTO? Hope-style VP Sales?)
2. Filter the matrix by primary persona — those are the features to lead with
3. For each feature you'll discuss, use the messaging hook as the opening talk-track
4. The benefit column is your "so what" answer; the positioning pillar tells you which broader story the feature ladders up to

**For marketing producing collateral:**
1. Pull the positioning pillar to anchor the asset's narrative
2. Use the messaging hook for headline copy
3. Use the benefit column for body copy and supporting points
4. Cross-reference variant pillar files for segment-specific emphasis

**For battlecard / objection-handling production:**
1. Filter by positioning pillar → identifies the messaging neighborhood
2. The "competitor weakness" implied by each unique feature becomes the rebuttal
3. Cross-reference `outputs/06-uvp-usp.md` Competitive Differentiation Matrix for the head-to-head dimension table

## Segment-Specific Application Notes

### Cash & Carry DSO (Color Street pattern)

**Lead in this order through the matrix:**
1. POS + sell-on-the-fly + vintage inventory (Pillar 1 — solve the catalog rotation objection first)
2. Per-rep ProPay merchant account + chargeback shift (Pillar 1 + 3 — CEO-level structural argument)
3. Customer record auto-creation (Pillar 3 — Edmond's "we don't own those customers")
4. Spendback (Pillar 2 — Brian's "that's great" + HyperWallet analogy)
5. LuLaRoe lineage + Paparazzi proof (adoption close)
6. Three-pillar FTC compliance (late-stage close, NOT opener)

**Avoid:**
- Leading with FTC (Brian reframed Wayroo as a sales tool, not a compliance tool)
- Per-nominal-active-rep pricing math without seller-vs-hobbyist qualification

### Hybrid DSO (Jordan Essentials pattern)

**Lead in this order through the matrix:**
1. Recovery story + Paparazzi proof (the outcome metric Hope and Nancy bought toward)
2. Customer record auto-creation (Nancy's "huge benefit")
3. Spendback (Nancy's "big benefit")
4. Rep performance dashboards via Wayroo widgets pulling Freedom data (Hope's "important")
5. POS + Media Library bundle as channel-shift catalyst (Nancy + Hope's own thesis)
6. Three-pillar FTC compliance (significantly de-emphasized — Jordan Essentials never raised it)
7. Dropship (Phase 2 expansion lever for non-C&C majority)

**Avoid:**
- Leading with FTC compliance entirely (confirmed negative finding)
- Over-pitching C&C-specific features to non-C&C-majority rep base
- Promising convention-launch outcomes without rep enablement plan

### Standard DSO (variant not yet built — provisional guidance)

**Lead in this order (until validated):**
1. Rep activation outcome + Paparazzi proof
2. Pillar 1 (rep experience + one-app framing)
3. Pillar 3 (customer data + dashboards)
4. Pillar 2 (architectural depth)

**Avoid:**
- Over-leading with C&C-specific features unless qualified
- Heavy compliance framing unless prospect raises it
