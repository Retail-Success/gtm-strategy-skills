# Prospect Intelligence Index

**How to use:**
- Each file = one prospect account
- Files are named `[company-slug].md`
- This index is the quick-reference table; each file has the full detail
- The SDR agent reads this folder before any outreach or call prep
- GTM skills (positioning, messaging, launch) use this as real-world validation data

**File naming:** `prospects/[company-slug].md`  
**Template:** `prospects/_template.md`

### Patterns added from the Jordan Essentials launch (July 17–18, 2026)

| Pattern | Accounts | GTM Implication |
|---------|----------|----------------|
| **Wayroo-led entry, back-office-agnostic** | **Color Street (Wayroo-only, no Freedom pitch) + Jordan Essentials (Wayroo attach to existing Freedom)** | **Two-account pattern, and potentially the largest strategic finding in the library.** Both live prospect records are Wayroo-first; neither was won by selling a back-office replacement. Wayroo is confirmed able to integrate with Exigo and other back offices. If Wayroo leads, the addressable market expands from "DSOs willing to replace a back office" to "any DSO" — including Exigo's installed base — and cycle time drops from 4–6 months to ~11 weeks. **Escalate to Unified Strategy as a category-level positioning decision (see `strategic-inputs.md` §9).** |
| **Rep tool spend ≥ $60/mo — quantified** | Jordan Essentials (Canva, ChatGPT, Square, Boards, Project Broadcast) | First hard dollar figure on rep tool spend. Wayroo arrives at $5 incremental inside a $15/mo eSuite fee. Reusable substitution argument for both rep and DSO pitches. Probe for the same figure in the next 2–3 accounts to promote to confirmed. |
| **Rep-side positioning must lead with selling, not organizing** | Jordan Essentials (~700 reps observed live) | Every top-tier rep reaction was an *earning* tool (Tap-to-Pay, invoicing w/ payment links) or a *seeing* tool (downline reports, dashboard widgets, phone access to back-office data). Compliance, media library, and inventory-organization features did not register at rep level. |
| **Feature persona split — DSO-high / rep-low** | Jordan Essentials (Media Library: Hope 🔴 High, reps 🔵 Low) | Buyer enthusiasm ≠ user adoption. Media Library is a DSO retention/brand-control feature, yet `strategic-inputs.md` §1 credits it against WAY-1 (Wayroo *active users*). **Target attribution appears misassigned — flag to Unified Strategy.** Audit other features for the same split. |
| **Self-reported C&C share is unreliable** | Jordan Essentials (~20% → confirmed understated at an account where ByDesign holds back-office data) | The qualifying question *"What % of your reps carry personal inventory?"* is producing bad data — DSO leadership likely does not know. **Replace self-report with back-office-derived measurement wherever ByDesign has the data.** Directly affects the 6 remaining Hybrid candidates. |
| **eSuite pass-through validated in production** | Jordan Essentials ($10/mo → $15/mo rep tier, Wayroo included) | Previously a theoretical pricing model. Now live: ~2,500 reps × $5 incremental ≈ $12.5K/mo to the DSO while ByDesign collects its per-user fee. Both sides net-positive. Use as a concrete pricing proof, not a hypothetical. |
| **Contract acceleration as a willingness-to-pay signal** | Jordan Essentials (Nancy pulled paid start forward to Sept 2026, cutting short an agreed free period) | A customer voluntarily shortening their own free period is a stronger WTP signal than any survey. Watch for this pattern; it is a candidate proof point for pricing conversations. |
| **ByDesign's own back office was part of the fragmented rep workflow** | Jordan Essentials | Reps previously logged into Freedom after each sale to manage inventory, or kept spreadsheets. Part of Wayroo's rep value is fixing a Freedom UX gap. **Internal framing only — not buyer-facing.** |
| **Rep demand for SMS / Project Broadcast** | Jordan Essentials (several unprompted requests) | Product gap. Note the competitive intersection: Project Broadcast already integrates with AiCE (at extra cost), and AiCE's Campfire offers group push notifications. Gives the unsigned AiCE partnership its first customer-demanded use case — or stands alone as a direct integration candidate. |


### Patterns added from the Pomifera Cart V3 demo (September 29, 2026)

> 🔴 These are **Freedom ecommerce (Cart V3 / Enrollment)** patterns, not Wayroo Land-and-Expand patterns. Keep the two systems separate.

| Pattern | Accounts | GTM Implication |
|---------|----------|----------------|
| ⭐⭐ **The orphan shopper — a customer arrives with no rep and has no way to find one** | **Pomifera (severity 5, VP Sales + technical lead, independently) + [PD-7267](https://bydesign.atlassian.net/browse/PD-7267) pre-existing from a separate client request (2026-08-14)** | **Strongest new positioning finding since the Nuvi demo.** This pain appears in **no** Cart V3 or Enrollment positioning doc and in no pain inventory. It belongs in Step 2 as a **Tier-1 unique attribute**, because it is the same structural class as U2a and U4: **Shopify has no distributor object, so it cannot offer "find a partner by name" at any price.** We have been making that architectural argument for enrollment while missing that it applies to the front door of the shopping journey. Confirm which client drove PD-7267 to promote this from probationary to confirmed. |
| **Surface resonance is segment-dependent — "demo the seam, not the surface" needs a qualifier** | **Nuvi Global** (mid-build, own modern storefront): *"it's pretty much the same"* vs. **Pomifera** (legacy cart, nothing built): *"you nailed it"* | The pitch kit's one rule was derived from a single Segment C account and applied universally. **For Segments C/D it holds. For Segments A/B — the priority-1 volume — the storefront is a genuine asset and should be shown with confidence.** Qualify the rule by segment in `07-cart-v3-pitch-kit.md`. |
| **Branding Studio is table stakes — muted reaction means "expected," not "unwanted"** | **Nuvi Global + Pomifera (both reacted positively but briefly)** | ⚠️ **Do not misread the quiet.** Self-serve storefront customization is now **standard in ecommerce — Shopify set that expectation**, and clients evaluate it as a baseline requirement rather than a novelty. Christina's *"this looks a lot like Shopify"* → *"you nailed it"* is **praise against the category standard**, not a lukewarm comparison. **Implication: the Studio must be present and credible — its absence would be disqualifying — but it cannot carry a demo, because meeting a standard generates less noise than solving a pain.** Show it with confidence, keep it tight, and spend the recovered minutes on what only we can do (the seam, the orphan shopper, AutoShip, shop-on-behalf). |
| **Enrollment resonance is conditional, not absolute** | Nuvi Global (*"best thing I've seen so far"*) + Pomifera (liked it, then immediately said it doesn't solve their problem without rep lookup) | Enrollment tested brilliantly where the client's pain was *the hand-off*. Where the pain is *rep discovery*, **enrollment without name search is a half-product.** Pitch the two joined; never demo enrollment without addressing who the shopper enrolls under. |
| **Abandoned-cart rate is a derivable proof point the client cannot see** | Pomifera (VP Sales: *"I can only imagine how many abandoned carts we have"*) | Mirrors the **Jordan Essentials** lesson that self-reported client figures are unreliable where ByDesign holds the back-office data. **We can compute the no-referrer drop-off from Freedom.** Converting a felt pain into a number is the strongest possible follow-up to this call — and reusable across the base. |
| **The client hands you the spec if you stop demoing** (probationary) | Pomifera (Christina produced the display fields, the privacy constraint and the failure mode unprompted) | Single account, but a clean sales-motion signal consistent with the pitch kit's *"then stop driving for ten minutes."* The presenter's *"feel free to interrupt"* was the highest-yield sentence in the call. **Book 60 minutes, not 30, for beta-track sessions** — this call ran out of time exactly when it became valuable. |

### Patterns added from the Sciteria Health Sciences Wayroo demo (November 2, 2026)

> ⚠️ Source is an **internal debrief** (Autumn and Dan, Revenue Leadership Meeting), not a first-party transcript. Every pattern here is probationary until the prospect's own words confirm it.

| Pattern | Accounts | GTM Implication |
|---------|----------|----------------|
| **White-label appetite depends on the segment** | **Color Street** (established C&C DSO, CEO: *"function over fashion"*) vs. **Sciteria** (startup founder: "didn't love anything branded Wayroo", wants full branding) | **Two accounts, opposite readings.** `06-persona-positioning.md` H1 says the only evidence points *against* white-label appetite, and that is now out of date. Founders building a brand want it, and established operators want function. **Neither will pay now:** one doesn't care, the other can't afford it. Price white-label as a growth path for startups, not an entry fee. |
| **Startups remove the adoption fight** | Sciteria (Autumn, and the room agreed) | The installed base's core Wayroo problem (~20–28% adoption) doesn't exist at a company that launches with the app. A **startup row** is missing from Wayroo positioning. The trade-off: a tiny field means near-zero payments revenue in year one, so Wayroo acts as a Freedom deal-closer here, not a revenue line. |
| **Automated field communication (notification center + autoresponders) is unpositioned** | Sciteria ("her favorite part") | No positioning doc mentions autoresponders or the notification center. Current copy says "corporate reaches the field", but the hook was **automation**: the field hears from the home office without anyone sending it. Test it as the lead Essentials benefit for lean and startup home offices. |
| **Media Library needs a condition to win the buyer** | Jordan Essentials (buyer high, reps low) + Sciteria (wants it only with an AI layer) | Media Library on its own doesn't carry a buyer conversation. The AI-layer request overlaps with the Aice partnership and with Fluid's AI positioning. Log it to product. Don't promise it. |
| **The Wayroo prospect price ladder is used live but not written down** | Sciteria ($5K / $10–15K gray label / ~$100K own app quoted or held back) | The repo anchor for white-label is $25K, and the prospect pitch still says [PRICING]. Write the ladder down before a second seller quotes different numbers. |
